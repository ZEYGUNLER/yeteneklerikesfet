# Cognitive Domain Mapping Table

This table maps the raw metadata generated by each game to the unified `CognitiveProfile` domains.

## 1. Attention (Dikkat)
*Ability to focus on relevant stimuli, sustain focus over time, and recover from distractions.*

| Source Game | Raw Metric | Contribution | Normalization Logic |
| :--- | :--- | :--- | :--- |
| **Dikkat Ormanı 2.0** | `attentionScore` | Primary | Direct map (0-100) |
| **Dikkat Ormanı 2.0** | `attentionRecoveryRate` | Secondary | Direct map (0-100), measures resilience |
| **Yıldırım Kulesi** | `missedStimuli` | Inverse | Decreases score based on omission errors |
| **Kristal Tapınak 2.0**| `transpositionErrors` (implied via focus) | Inverse | Decreases score (lack of focus on exact sequence) |

## 2. Inhibition (Dürtü Kontrolü)
*Ability to suppress impulsive responses and ignore distractors.*

| Source Game | Raw Metric | Contribution | Normalization Logic |
| :--- | :--- | :--- | :--- |
| **Dikkat Ormanı 2.0** | `inhibitionScore` | Primary | Direct map (0-100) |
| **Dikkat Ormanı 2.0** | `falseAlarms` | Inverse | Count directly lowers score |
| **Yıldırım Kulesi** | `falseStarts` | Inverse | Decreases score heavily (anticipation error) |
| **Yıldırım Kulesi** | `distractorTaps` | Inverse | Decreases score (distractor failure) |
| **Hazine Haritası** | `impulsiveStarts` | Inverse | Decreases score (starting before planning) |

## 3. Processing Speed (İşlem Hızı)
*Speed of visual scanning, cognitive throughput, and motor reaction.*

| Source Game | Raw Metric | Contribution | Normalization Logic |
| :--- | :--- | :--- | :--- |
| **Yıldırım Kulesi** | `reactionTimeMedian` | Primary | Sigmoid inverse map (e.g., 300ms = 95, 800ms = 30) |
| **Yıldırım Kulesi** | `consistencyScore` | Secondary | Modulates speed score to reward stable performance |
| **Dikkat Ormanı 2.0** | `avgReactionTime` | Secondary | Weighted against baseline age expectations |

## 4. Working Memory (Çalışan Bellek)
*Capacity to hold, update, and retrieve spatial/sequential information.*

| Source Game | Raw Metric | Contribution | Normalization Logic |
| :--- | :--- | :--- | :--- |
| **Kristal Tapınak 2.0**| `maxSpanReached` | Primary | Logarithmic scale (Span 3 = 40, Span 8 = 100) |
| **Kristal Tapınak 2.0**| `retrievalAccuracy` | Secondary | Modulates max span score by success rate |
| **Kristal Tapınak 2.0**| `avgSpatialDistanceError`| Inverse | Punishes score heavily for wildly inaccurate spatial recall |

## 5. Planning (Planlama & Yürütücü İşlev)
*Foresight, strategic execution, and efficiency of decision making.*

| Source Game | Raw Metric | Contribution | Normalization Logic |
| :--- | :--- | :--- | :--- |
| **Hazine Haritası** | `planningScore` | Primary | Direct map (0-100) |
| **Hazine Haritası** | `efficiencyScore` | Secondary | Ratio optimal/actual; mapped linearly (1.0 = 100) |
| **Hazine Haritası** | `replanningEvents` | Inverse | Punishes score for failing execution mid-route |
| **Hazine Haritası** | `deadEndsVisited` | Inverse | Decreases score (poor foresight) |
| **Hazine Haritası** | `avgDecisionTime` | Contextual| Differentiates slow methodical planners from fast impulsive ones |
